## Проверки

- nbformat, синтаксис Python, сохранность кода и outputs, SHA-256, целостность ZIP.
- RealNVP: обратимость, компенсация logdet, согласие с autograd.
- DDPM: восстановление при известном шуме; допустимая posterior variance; последний шаг без добавочного шума.
- Inpainting: точное сохранение известных пикселей; MSE только по пропуску.
- CycleGAN: включённая ветка inference проверена на CPU с предварительно загруженными официальными весами; forward 1,693 с.
- Теория: 28 ссылок на 15 страниц fpakhurov; HTTP 200, якоря найдены. Отчёт: validation/theory_links.json.
- Схемы: шесть внешних PNG, авторство и URL указаны в assets/architecture_links.json и SOURCES.md. Для отображения требуется интернет.
- HTML: формулы, шрифты и экспериментальные изображения встроены; исполняемых внешних скриптов нет.
