## Проверки

- nbformat, синтаксис Python, соответствие notebooks исходникам сборки, отсутствие ошибок в outputs, SHA-256 и целостность ZIP.
- MNIST: контрольные суммы четырёх IDX-архивов, размер 28×28; независимые официальные train/test, стратифицированные подвыборки 12 000/2 000.
- RealNVP: обратимость, компенсация logdet, согласие с autograd. Для условного потока сравнивается marginal NLL смеси, а не условный NLL с дополнительной информацией о классе.
- DDPM: восстановление при известном шуме; конечная неотрицательная posterior variance; последний шаг без дополнительного шума.
- Inpainting: известные пиксели сохранены точно; ошибка оценивается только на пропуске. Это приближённая проекция.
- TAESD: выполнен предобученный inference на обеих фотографиях; проверены SHA-256 кода, весов и изображений. Лицензии: [PETS_LICENSE.md](assets/PETS_LICENSE.md).
- CycleGAN: сохранён проверенный CPU inference horse→zebra; новый inference по умолчанию выключен.
- Теория: 31 ссылка на 16 страниц fpakhurov; HTTP 200, используемые якоря найдены. Отчёт: `validation/theory_links.json`.
- Схемы: шесть внешних PNG, авторство и URL указаны в `assets/architecture_links.json` и SOURCES.md. Для отображения требуется интернет.
- HTML: формулы, шрифты и экспериментальные изображения встроены; внешних исполняемых скриптов нет. Проверен рендеринг KaTeX.
