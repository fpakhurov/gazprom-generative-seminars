**Газпром · 2×90 минут · Python и основы нейросетей.**

| Занятие | Содержание |
|---|---|
| 1 | AE → VAE → DCGAN; смена класса в cVAE/cGAN; фотографии кошки и собаки, CycleGAN |
| 2 | RealNVP → условный DDPM; управление классом и CFG; один опыт редактирования или inpainting |

| Блокнот | Google Colab |
|---|---|

- Формат: тезисы, схемы, формулы, готовый код и управляемые эксперименты.
- Развитие методов: реконструкция → вероятностные коды; состязательное обучение; обратимые преобразования; последовательное удаление шума. Семейства сопоставляются по механизмам и ограничениям.
- Основные данные: MNIST 28×28 (12 000 train / 2 000 test) и двумерные точки. Исходные пиксели используются без увеличения из 8×8.
- Метка задаёт целевой класс; случайный код сохраняет разнообразие внутри класса. Соответствие классу проверяется по результату.
- Первоначальная загрузка MNIST — около 12 MB; данные и веса кэшируются в `data/`.
- [Цифры 28×28](assets/mnist_training_preview.png) · [опыт на фотографиях](assets/pets_reconstruction.jpg).
- Фотографии кошки и собаки 256×256: предобученный TAESD, реконструкция и возмущение латентного кода; около 10 MB весов.
- Сравнение семейств: целевая функция, процедура генерации, вычислительная стоимость и ограничения. Методы развивались параллельно.
- LLM не рассматриваются. Подробный код условных расширений и второй опыт восстановления предназначены для самостоятельной работы.

## Запуск

1. Открыть блокнот по ссылке Colab в таблице выше.
2. Оставить Python 3; для обучения свёрточных сетей рекомендуется GPU T4, доступен и CPU. При необходимости сохранить копию в свой Google Drive.
3. Выбрать **Среда выполнения → Выполнить все**.
4. Для 90-минутного маршрута использовать [тайминг](INSTRUCTOR_GUIDE.md): основные механизмы, готовые результаты и один управляемый опыт; подробный разбор расширений — после занятия.

- До занятия выполнить оба блокнота и сохранить результаты; обучение не должно занимать время обсуждения.
- Google Drive и API-ключи не требуются.
- CycleGAN по умолчанию использует сохранённую иллюстрацию. Новый inference: RUN_CYCLEGAN_DEMO=True; нужны интернет и загрузка около 46 MB весов.
- После изменения архитектуры или расписания шума повторить создание модели и оптимизатора.

Локальное воспроизведение в отдельном окружении Python 3.11+:

    python -m pip install -r requirements.txt
    python -m ipykernel install --prefix "$VIRTUAL_ENV" --name python3
    python scripts/validate_notebooks.py 01_vae_gan.ipynb 02_flows_diffusion.ipynb

Исходники сборки находятся в scripts/. HTML доступен без выполнения Python; для внешних архитектурных схем требуется интернет; сохранённые результаты позволяют проводить разбор без повторного обучения.

Проверено локальное выполнение; hosted Colab отдельно не тестировался. Демонстрации на малых данных не подтверждают эффективность на производственных задачах.
