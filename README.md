# Генеративные модели: практические семинары

**Газпром · 2×90 минут · Python и основы нейросетей.**

**Редакция 5 ноября:** добавлены подробные заметки, пояснения к регуляторам и live-preview GAN/cGAN. Полный повторный прогон отложен по запросу; выполнены синтаксические и изолированные проверки нового вывода. Сохранённые outputs помечены как примеры v1.2.0. На занятие: 75 минут основного материала + 15 минут резерва.

- Формат: тезисы, схемы, формулы, готовый код и управляемые эксперименты.
- Сквозная задача: получить новые объекты, управлять классом и проверить результат. Переходы объясняются наблюдаемыми ограничениями: случайные коды AE → prior/posterior VAE; другой критерий GAN; точная плотность потока; последовательная генерация DDPM.
- Основные данные: MNIST 28×28 (12 000 train / 2 000 test) и двумерные точки. Исходные пиксели используются без увеличения из 8×8.
- Метка задаёт целевой класс; случайный код сохраняет разнообразие внутри класса. Соответствие классу проверяется по результату.
- Первоначальная загрузка MNIST — около 12 MB; данные и веса кэшируются в `data/`.
- [Цифры 28×28](assets/mnist_training_preview.png) · [опыт на фотографиях](assets/pets_reconstruction.jpg).
- Фотографии кошки и собаки 256×256: предобученный TAESD, реконструкция и возмущение латентного кода; около 10 MB весов.
- Сравнение семейств: целевая функция, процедура генерации, вычислительная стоимость и ограничения. Методы развивались параллельно.
- LLM не рассматриваются. CycleGAN, inpainting, выводы формул и подробный код расширений предназначены для самостоятельной работы; CycleGAN можно кратко показать при наличии свободного времени.

## Запуск

1. Открыть блокнот по ссылке Colab в таблице выше.
2. Оставить Python 3; для обучения свёрточных сетей рекомендуется GPU T4, доступен и CPU. При необходимости сохранить копию в свой Google Drive.
3. В первой ячейке выбрать `QUICK_MODE` при необходимости, выполнить её и затем **Среда выполнения → Выполнить все**. Для качественных учебных генераций оставить quick выключенным; quick — короткая проверка кода.
4. Во время GAN/cGAN сравнивать примеры на фиксированном шуме и D scores. Перед циклом видны режим, устройство и число шагов.
5. Во время фонового выполнения следовать [сценарию занятия](INSTRUCTOR_GUIDE.md): 75 минут ядра, один управляемый опыт и 15 минут резерва. Повторно запускать только короткие ячейки генерации/редактирования.

- Ведущему: до занятия выполнить оба блокнота и открыть сохранённые результаты. Участникам: запустить «Выполнить все» один раз в начале, затем обсуждать только основной маршрут.
- Дополнительные ячейки могут задавать зависимости основных опытов; необязателен их разбор, первоначальное выполнение сохраняется. Если запуск задерживается, использовать готовые outputs и продолжать обсуждение.
- API-ключи и монтирование Drive не требуются. Для подключения Colab нужен вход в Google; оба занятия запускать последовательно.
- CycleGAN по умолчанию использует сохранённую иллюстрацию. Новый inference: RUN_CYCLEGAN_DEMO=True; нужны интернет и загрузка около 46 MB весов.
- После изменения архитектуры или расписания шума повторить создание модели и оптимизатора.

Локальное воспроизведение в отдельном окружении Python 3.11+:

    python -m pip install -r requirements.txt
    python -m ipykernel install --prefix "$VIRTUAL_ENV" --name python3
    python scripts/validate_notebooks.py 01_vae_gan.ipynb 02_flows_diffusion.ipynb

Исходники сборки находятся в scripts/. HTML доступен без выполнения Python; для внешних архитектурных схем требуется интернет; сохранённые результаты позволяют проводить разбор без повторного обучения.

Версия v1.2.0 прошла полные запуски локально и в Google Colab на Tesla T4. Для текущей редакции полный запуск пока не повторялся; см. VALIDATION.md. Демонстрации на малых данных не подтверждают эффективность на производственных задачах.
